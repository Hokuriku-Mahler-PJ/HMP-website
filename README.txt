HMP website prototype
=====================

Contents
- index.html: responsive single-page homepage prototype

How to preview
1. Unzip the downloaded archive.
2. Open index.html in a modern web browser.

Before publishing
- Replace the temporary event date, venue and programme.
- Replace the mailto placeholder CONTACT-EMAIL-TO-BE-SET with the official contact email.
- Replace the CSS-generated visual placeholders with approved HMP photos and logo.
- Replace the draft ABOUT text with HMP's confirmed mission and profile.
- Add the real external ticket URL when ticket sales open.
- Obtain consent for identifiable member photos before publishing.

This is a static prototype, not yet connected to a ticket provider, CMS, or live inquiry form.
It can be used as a visual reference when rebuilding the site in Studio, Wix, or another platform.
